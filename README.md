# Webdown

## Introduction
Webdown is a real-time Markdown to HTML converter that transforms your Markdown into beautiful, responsive web pages. It features live preview, multiple themes, project management, and one-click HTML export.

## Features
- Live Markdown editing with instant preview  
- 3 professional themes: Blog, Portfolio, Docs  
- Project management: save, load, delete projects  
- Automatic table of contents generation  
- Word count and reading time statistics  
- Export to standalone HTML  
- Responsive design with optional dark mode  
- Syntax highlighting, tables, quotes, and lists

-Backend
-cd backend
-python app.py

-Server runs on http://127.0.0.1:5000

-Frontend
-Open frontend/index.html in a browser.

##Workflow
1.Write Markdown in the editor panel.
2.Preview renders instantly.
3.Switch themes using the sidebar (Blog/Portfolio/Docs).
4.Save projects to persist content and preview.
5.Export HTML as a standalone file.
6.Load or delete projects as needed.
